# Serving plans

Cooks offers Plan a serving time and compact Upcoming cards. A plan contains a reviewed setup and independent dish/side schedules, pinned serving instant and timezone, preparation/preheat windows, cooking ranges, separate rest/hold and an explicit buffer. Saving does not fabricate a cook start or record the grill; Review and start opens the normal setup form.

Ranges use user-entered durations unless the user chooses a recorded range. Comparable evidence requires completed, unambiguous Food on→Remove history with matching available cut, food type, smoker, size, start, bone-in, setpoint and wrap; each cook contributes once. A single cook is labelled a reference. No linear weight extrapolation or confidence percentage is generated.

Overlapping pit-temperature needs are surfaced and must be reconciled by adjusting temperature/time or selecting separate cooking equipment. No second simultaneous grill recording is added. Active ready windows move with actual Food on and Remove milestones and retain the evidence label. Local daylight-saving gaps are rejected; repeated times offer the two offsets explicitly.

Upcoming and active serving plans are local versioned archive records. Starting uses an immutable book snapshot with new dish mapping, even if the source playbook later changes.
